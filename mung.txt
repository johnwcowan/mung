# The mung program

usage: see mung.py, mung_gc.py
       mung-gc [destroy file ...]

Editing commands: see repl.py, help.py

Environment variables:
MUNG_STATE_TREES   Directory to store mung states, defaults to $HOME/.mung
VISUAL             Editor used by e command
EDITOR             Used if VISUAL is not defined, defaults to vi
PAGER              Pager used by p command, defaults to less.
SHELL              Shell for |, !, and script commands

Shell syntax: %x% for state tag/number

For the garbage collector, see gc.md

Files in the state directory:
0               copy of original file
1-n             cached state files
filename	name of file being munged
current         the current state id
state.json	the state object with these top-level keys:
        states (list of state commands, descriptions, and dependencies)
        tags (map from tags to state numbers)
        undo_stack (stack of undos performed)
        jump_stack (stack of jumps performed)
